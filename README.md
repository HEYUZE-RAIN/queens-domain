# Queen's Domain · 全收集互动地图

《女巫魔域》（Queen's Domain）的非官方中文全收集互动地图。纯静态单页，不联网、不读取游戏文件，所有进度只保存在你自己的浏览器里。

## 功能

| 模块 | 说明 |
|---|---|
| **收集清单** | 162 个收集位置，按分类分组；含银骷髅、奥贝瓦之卵、鸭子雕像、第二视觉镜片、七零八落、武器、饰品、NPC、钥匙物品等 |
| **成就 / 奖杯** | 53 项成就，含进度环与「尚未获得」筛选 |
| **怪物图鉴** | 188 条图鉴，标出秘密 Boss 与受地形变化影响的条目 |
| **极致功利白金** | 一周目四结局速通动线，11 段。**含剧透与破序，首次游玩勿开** |
| **魔典 33 条** | 女巫魔典全部代码，点击即复制。**同样剧透** |

大地图支持点击任意区域弹出该区域的收集进度、分类明细与可通往区域，并可跳转逐区域细部图。

后两个页签进入时会先弹出剧透警告遮罩，**确认前不渲染任何内容**，确认状态会记住。

## 使用

直接打开 `index.html` 即可，无需服务器、无需安装。

离线使用：把 `index.html` 与 `assets/` 一起拷走即可。

本地起服务（可选，避免部分浏览器的 file:// 限制）：

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

## 操作

- **点击区域**（整块岛可点）→ 区域详情弹窗
- **拖拽**平移，**滚轮**缩放
- `+` / `-` 缩放，`0` 复位视图，`1`–`5` 切换页签，`Esc` 逐层关闭
- 侧栏可收起，把地图放到最大
- 右侧图例默认收起，点开可切换标记显隐

## 数据准确性

结构化字段（分类、区域归属、需求条件）来自公开攻略与社区整理的交叉核对；**备注里的走法与说明属于整理与推断**，可能因游戏版本差异失效。若与游戏内不一致，以游戏为准。

内容由 AI 深度参与生成，页面内「关于」有完整的可靠性分层说明与免责声明。

## 技术

原生 JavaScript + 内联 SVG，无框架、无构建步骤、无外部依赖。

```
index.html            单页入口
assets/
  style.css           基础样式
  extra.css           组件与文档样式
  zone.css           区域细部图样式
  regions.js          20 个区域的锚点、地标与连接数据
  mapstyle.js         18 座岛屿轮廓、配色与纹理
  mapdraw.js          大地图绘制、区域弹窗
  zonemap.js          区域细部图
  pins.js             162 个收集点
  achievements.js     53 项成就
  bestiary.js         188 条图鉴
  route.js           白金路线数据
  routeui.js         路线与魔典页渲染、剧透遮罩
  ...
check-region-icons.js 区域图标校验脚本（开发用）
```

进度存储键名前缀 `qd_`，均存于 `localStorage`。

### 开发校验

改动区域位置后，运行校验脚本确认图标没有跑出区域：

```bash
npm i playwright-core
python -m http.server 8777
node check-region-icons.js
```

检查项：锚点 / 地标 / 区域名标签是否都在各自轮廓内、所有区域是否在视野内、任意两块区域轮廓是否相交。
